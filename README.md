# 🇺🇸 EN-US

## 🏬 Shopping Center Manager

Project developed for the **Laboratory I** course in the **Information Systems** program at **Unisinos University**.  
The goal of this system is to manage stores and products in a shopping center, applying **Object-Oriented Programming (OOP)** concepts in **Java**.

---

### 📘 About the Project

The **Shopping Center Manager** allows you to:
- Create and manage **stores** of different types (Clothing, Cosmetics, Food, Computing, Jewelry);
- Register **products** with name, price, and expiration date;
- Manage and query **shopping data**, such as the number of stores by type and the computing store with the highest electronics insurance value.

The project was developed using **Java 17** and the **IntelliJ IDEA** IDE.

---

### ⚙️ Technologies Used

- **Java 17**
- **IntelliJ IDEA** (for development)
- **Paradigm:** Object-Oriented Programming (OOP)

---

### 🚀 Main Features

- Create new **stores** and **products** via terminal input;
- Count stores by type;
- Identify the **computing store** with the highest electronics insurance value;
- Store and display data in a structured way.

---

### 📂 Class Organization

- `models/`: Contains the main domain classes of the project (`Store`, `Product`, `Shopping`, etc.);
- `create/`: Contains classes responsible for the interactive creation of objects (`CreateStore`, `CreateProduct`);
- `subStores/`: Contains subclasses that extend `Store` and represent specific store types;
- `Main.java`: Entry point of the program containing the main menu.

# 🇧🇷 PT-BR
## 🏬 Shopping Center Manager

Projeto desenvolvido na disciplina **Laboratório I** do curso de **Sistemas da Informação - Unisinos**.  
O objetivo do sistema é gerenciar lojas e produtos de um shopping center, aplicando conceitos de **Programação Orientada a Objetos (POO)** em **Java**.

---

### 📘 Sobre o Projeto

O **Shopping Center Manager** permite:
- Criar e gerenciar **lojas** de diferentes tipos (Roupas, Cosméticos, Alimentação, Informática, Joias);
- Cadastrar **produtos** com nome, preço e data de validade;
- Controlar e consultar **informações do shopping**, como quantidade de lojas por tipo e loja de informática com o maior seguro eletrônico.

O projeto foi desenvolvido em **Java 17**, utilizando a **IDE IntelliJ IDEA**.

---

### ⚙️ Tecnologias Utilizadas

- **Java 17**
- **IntelliJ IDEA** (para desenvolvimento)
- **Paradigma:** Programação Orientada a Objetos (POO)

---

### 🚀 Funcionalidades Principais

- Criar novas **lojas** e **produtos** via terminal;
- Contar lojas por tipo;
- Identificar loja de informática com maior valor de seguro eletrônico;
- Armazenar e exibir dados de forma estruturada.

---

### 📂 Organização das Classes

- `models/`: Contém as classes principais do domínio do projeto (`Store`, `Product`, `Shopping`, etc.);
- `create/`: Classes responsáveis pela criação interativa de objetos (`CreateStore`, `CreateProduct`);
- `subStores/`: Subclasses que herdam de `Store` e representam diferentes tipos de lojas;
- `Main.java`: Ponto de entrada do programa, contendo o menu principal.
